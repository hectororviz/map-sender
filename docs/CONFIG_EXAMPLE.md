# Ejemplo de configuración (SIN credenciales reales)

Rellena estos valores en la app (Ajustes). No los pongas en el repo.

```
URL base Gotify:      https://gotify.tu-dominio.example
Token de aplicación:  <pegar-token-generado-en-gotify-apps>
Nombre dispositivo:   movil-ejemplo
Prioridad:            5
App navegación:       WAZE
Añadir navigate=yes:  sí
Confirmar envío:      no (automático; pon sí para revisar antes)
Timeout (s):          15
Reintentar:           sí
```

Cómo obtener el token: Gotify Web → Apps → Create application → copiar token (se muestra una sola vez).
